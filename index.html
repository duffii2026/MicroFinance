DEVELOPER GUIDE

Connect to MFS step by step

Open full guide
  1. 01
    Choose your module

    Open a module below and review its workflow mapping. The module ID is part of every records URL.

  2. 02
    Create a scoped API key

    Sign in as an administrator in the key manager. Name the integration, select only the needed modules, choose an expiry, and copy the key once.

  3. 03
    Set your base URL and key

    Use the base URL above and send Authorization: Bearer YOUR_MFS_API_KEY with each records or file request.

  4. 04
    Check the service, then read or write

    Call GET /health first. Then use the selected module's collection route to list, create, replace, or delete JSON records.

  5. 05
    Map fields and attach files

    Agree field names and stable IDs with the MFS team. Upload related files through /files and save the returned file ID with your record.

Data boundary: the shared API stores records in MySQL, while original module screens retain their existing browser storage. API changes do not automatically appear in those screens until an explicit sync or migration is built.
