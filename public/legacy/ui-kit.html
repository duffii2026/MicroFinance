One language for all 19 modules. Every control below is rendered by the shared kit (/ui-kit.css) on top of the module palette — so the same markup looks identical in MM1, MM2, MM4 and the React workspace, and follows each module’s dark mode automatically.

Try me: click into fields, tab through them, hover and press the buttons. Focus rings, hover, active, disabled and error states are all part of the kit.

UsageThree rules keep it consistent.

1. Load <link rel="stylesheet" href="/ui-kit.css"> after the module’s own styles.
2. Use .btn for actions (.pri, .danger, .sm) and .i for inputs — or plain <input>, <select>, <textarea>, which are styled anyway.
3. Wrap each control in class="f" with a .hint or .err line; mark required fields class="f mfs-required".
